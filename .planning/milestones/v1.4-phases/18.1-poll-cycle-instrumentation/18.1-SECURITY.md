## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| worker goroutine → parent `runCycle` frame | Per-artist results cross a goroutine boundary with no `-race` net (D-14). Only `artistResult` values on a `len(entries)`-buffered channel cross it — no shared mutable counter. | `artistResult{checked, errored, events}` — non-sensitive integers/bools |
| upstream API response → `runOneArtist` | A malformed MusicBrainz/Deezer payload can panic a worker; the recovered panic value is arbitrary attacker-influenced data. | recovered `panic_value` (attacker-influenced) |
| cron tick → `runCycle` CAS overlap guard | A tick arriving during a live cycle must be rejected atomically; a wrong decision double-polls or wedges the source. | `atomic.Bool` CAS result — no data |
| `runCycle` → `pollruns.Store` (in-process seam) | Everything written here is later readable through the gated `/status` endpoint. The `RunResult` entry is the disclosure surface; the failure-path entry especially. | counts, timestamps, `cycle_id`, `source`, `outcome` enum — operator-visible, no secrets |
| `watchlist.Store.List` error → recorded run entry | The underlying driver error is wrapped into `runCycle`'s return value; none of it may reach a `RunResult` field. | wrapped driver error (stays in return value only) |
| `pollruns.Store` → `/status` HTTP response | Frozen by Phase 18 and out of this phase's scope, but it is the sink that makes the seam above matter. | `SourceSnapshot` (race-free copy) |
| local gate → CI | CI has neither `-race` nor this box's constraints; whatever the local gate passes ships. | test/lint results |

## Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation | Status |
|-----------|----------|-----------|----------|-------------|------------|--------|
| T-18.1-01 | Information disclosure | `runCycle` `pollruns.RunResult` literal | high | mitigate | Literal populates counts, timestamps, `cycle_id`/`source`, and the `outcome` enum only; `Summary` left unset (`poller.go` recorder defer). `Store.RecordRun` recomposes `Summary` via `composeSummary` (outcome + 3 counters, `pollruns.go:124`) so a caller value can never reach a snapshot. | closed |
| T-18.1-02 | Information disclosure | `runOneArtist` recovered `panic_value` log attribute | low | accept | Pre-existing and unchanged: `panic_value` goes to the operator-only structured log correlated by `cycle_id`/`artist_mbid`, never into a `RunResult` (`runOneArtist` recover block). | closed |
| T-18.1-03 | Denial of service | deferred `p.runs.RecordRun` call | high | mitigate | Log-and-swallow — `logger.Error("record poll run failed", …)`, never returned, mirroring `NotifyPending`. Store append is a synchronous mutex write that cannot block. Verified by `TestRunRecorder_ErrorSwallowed`. | closed |
| T-18.1-04 | Tampering (self-inflicted) | per-cycle counters | high | mitigate | Single-threaded `for r := range resultCh` fold after `wg.Wait()`; `artistsSkipped++` only in the dispatch loop; zero `atomic.` references in the `runOneArtist` region (D-14). Verified by `TestRunCycle_CounterInvariant` (1000 iters, exact equality, `-count=3`). | closed |
| T-18.1-05 | Denial of service | `resultCh` buffer capacity | high | mitigate | `resultCh := make(chan artistResult, len(entries))` — capacity ≥ sender count, so no worker blocks on send, every worker reaches `wg.Done()`, `wg.Wait()` always returns. Grep-gated in plan 01, exercised ~1000× in `TestRunCycle_CounterInvariant`. | closed |
| T-18.1-06 | Spoofing / repudiation | run-entry provenance (`cycle_id`, `source`) | low | accept | `cycle_id` is `fmt.Sprintf("%s-%d", source, nextCycleID.Add(1))` from a process-local counter; `source` is a package constant. No external input path into either; history is in-process and non-authoritative by design (ADR-0001). | closed |
| T-18.1-07 | Information disclosure | `store.List` error path run entry | high | mitigate | `cycleErr = fmt.Errorf("poller: list watchlist: %w", err); return cycleErr` — the wrapped driver error leaves as the return value only; the `RunResult` gets `outcome=error` and zero counters. `composeSummary` emits no error text. Verified by `TestRunRecorder_RecordsErrorOutcomeOnListFailure` (asserts sentinel text absent from summary). | closed |
| T-18.1-08 | Denial of service | run-history eviction by skip-storm | medium | mitigate | `RecordSkip` only bumps `consecutiveSkips` and stamps `lastSkippedAt` — no ring append (`pollruns.go:98`). Verified by `TestRunRecorder_SkipRecordsNoEntry` (history length unchanged across a skipped tick). | closed |
| T-18.1-09 | Denial of service | overlap guard (`atomic.Bool` + `defer running.Store(false)`) | high | mitigate | Recorder defer registered *after* `defer running.Store(false)`, so LIFO runs the recorder first and the guard release last, unconditionally (incl. panic). Verified by `TestRunRecorder_ErrorSwallowed` (asserts `mbRunning` false after an erroring and a slow recorder). | closed |
| T-18.1-10 | Denial of service | recorder retry loop | medium | mitigate | Failure is logged once and dropped — no retry, no backoff, no queue. Verified by the exactly-one run-counter check in `TestRunRecorder_ErrorSwallowed`. | closed |
| T-18.1-11 | Tampering (self-inflicted) | counter correctness under fan-out with no race detector | high | mitigate | `TestRunCycle_CounterInvariant`: ~1000 iterations, `WithMusicBrainzWorkers(8)`, K=3 erroring + P=2 panicking artists, exact-equality assertions only, run at `-count=3`; acceptance grep confirms no `>=`/`<=` in the test body. | closed |
| T-18.1-12 | Repudiation | undocumented `-race` waiver | medium | mitigate | Broken Windows Ledger entries 12 (18.1-01) and 13 (18.1-03) name the substitution and the compensating control (`TestRunCycle_CounterInvariant`), matching the 9/10 precedent — the waiver is auditable, not silent. | closed |
| T-18.1-13 | Information disclosure | frozen `/status` contract | low | mitigate | `git diff d77b3a7..HEAD` over `docs/api/status-contract.md` and `web/` is empty. This phase populates `events_recorded` and makes `cancelled` reachable — both already declared — and changes no key or type. | closed |
| T-18.1-SC | Tampering (supply chain) | npm/pip/cargo installs | low | accept | No package-manager install anywhere in the phase — every symbol is in-repo or Go stdlib. RESEARCH.md "Package Legitimacy Audit": not applicable; no `[ASSUMED]`/`[SUS]`/`[SLOP]` entries. | closed |
