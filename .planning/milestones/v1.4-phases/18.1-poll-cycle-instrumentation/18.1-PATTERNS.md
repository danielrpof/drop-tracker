## Pattern Assignments

### `internal/poller/poller.go` — `runOneArtist` helper (extract from the worker goroutine)

**Analog:** the current worker goroutine body, `poller.go:358-397` (read this session).

**Current body to move into the helper** (`poller.go:359-397`):
```go
go func(entry watchlist.Entry) {
	defer wg.Done()
	defer func() { <-sem }()
	defer func() {
		if r := recover(); r != nil {
			logger.Error("poll worker panicked",
				slog.String("artist_mbid", entry.MBID),
				slog.String("artist_name", entry.Name),
				slog.Any("panic_value", r),
			)
		}
	}()
	if err := ctx.Err(); err != nil {
		return
	}
	fetchAndRecord(ctx, logger, entry)
}(entry)
```

**Target shape** (RESEARCH.md lines 134-187 has the full recommended code):
- New unexported `type artistResult struct { checked, errored bool; events int }`.
- New `func runOneArtist(ctx, logger, entry, fetchAndRecord) (res artistResult)` — the
  deferred `recover()` keeps the **exact** `logger.Error("poll worker panicked", …
  slog.Any("panic_value", r))` line (security: panic value stays in logs, never in a
  `RunResult`), and additionally sets `res = artistResult{checked: true, errored: true}`.
- Goroutine body collapses to: `defer wg.Done(); defer func() { <-sem }(); resultCh <- runOneArtist(ctx, logger, entry, fetchAndRecord)`.
- **Do not touch** the `wg.Add(1)` / `select { case sem <- struct{}{}: case <-ctx.Done(): … break dispatch }` / `dispatch:` label / `wg.Wait()` (CONTEXT "Minimal diff"; RESEARCH Anti-Patterns).

**Preserve this comment intent** (currently `poller.go:362-372`): the "panics do not cross
goroutine boundaries" rationale. Trim to 1-3 lines per CLAUDE.md comment discipline; one
`PERF-03` reference is enough.

### `internal/poller/poller.go` — buffered result channel + single-threaded fold

**Analog:** `pollruns_test.go:TestStore_TwoSourceConcurrent` (lines 282-333) — the
project's canonical "no `-race`, so exact-equality + repetition instead" structure.

**Core pattern** (RESEARCH.md lines 195-211):
```go
resultCh := make(chan artistResult, len(entries)) // capacity >= senders — see concurrency section
// ... dispatch loop: `if !shouldDispatch(entry, logger) { artistsSkipped++; continue }` ...
wg.Wait()
close(resultCh)

var artistsChecked, artistsErrored, eventsRecorded int
for r := range resultCh {
	if !r.checked {
		continue
	}
	artistsChecked++
	if r.errored {
		artistsErrored++
	}
	eventsRecorded += r.events
}
```

- `artistsSkipped` is incremented **only** in the single-threaded dispatch loop at the
  existing `if !shouldDispatch(entry, logger) { continue }` (`poller.go:347-349`) — never
  via the channel.
- The fold sits between `wg.Wait()` (`poller.go:399`) and the post-join `ctx.Err()`
  re-check (`poller.go:411-413`).

**RecordSkip placement** — the pre-CAS branch, `poller.go:314-317`:
```go

	p.logger.Warn("skipping poll cycle: previous cycle still in progress", slog.String("source", source))
	p.runs.RecordSkip(source) // ★ NEW — before the return, no cycleID needed
	return ErrCycleInProgress

defer running.Store(false)
```

**RecordRun defer** — registered right after `defer running.Store(false)` (LIFO → RecordRun
runs first, guard still held). Full assembled code in RESEARCH.md lines 218-264 and 562-589.
Key points:
- `outcome` switch keys off the existing `var cycleErr error` (`poller.go:343`):
  `errors.Is(cycleErr, context.Canceled) || errors.Is(cycleErr, context.DeadlineExceeded)` →
  `pollruns.OutcomeCancelled`; other non-nil → `pollruns.OutcomeError`; nil → `pollruns.OutcomeOK`.
- `store.List` error path (`poller.go:325-327`) must become
  `cycleErr = fmt.Errorf("poller: list watchlist: %w", err); return cycleErr` (Pitfall 6).
- Capture `runFinishedAt` / `runDurationMS` at the existing "poll cycle complete" log point
  (`poller.go:415-418`) and reuse in the log line (replace `time.Since(cycleStart)`); the
  defer reads the captured vars, with an `if runFinishedAt.IsZero()` fallback for the early
  `List`-error return. **Never** call `time.Now()` in the defer on the happy path (Pitfall 4).
- Pass `ctx` straight to `RecordRun` — `pollruns.Store.RecordRun(_ context.Context, …)`
  ignores it (`pollruns.go:79`). No `context.WithoutCancel`.
- **Do not set `RunResult.Summary`** — `RecordRun` overwrites it via `composeSummary`
  (`pollruns.go:82,124-127`). Security gate (ASVS V7): no `err.Error()` into any `RunResult` field.

`pollruns.RunResult` field set (`pollruns.go:39-51`) matches CONTEXT exactly — no mismatch.
`errors` and `time` are already imported in `poller.go` (lines 19-24); add nothing.

existing `slog.Any("panic_value", r)` line (`poller.go:377`).

into any `RunResult` field. Per-artist detail stays in the `cycle_id`-correlated logs.
Grep gate: no `err.Error()` argument inside a `pollruns.RunResult{…}` literal.
