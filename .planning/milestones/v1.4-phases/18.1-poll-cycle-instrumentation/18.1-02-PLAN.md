<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| cron tick → `runCycle`'s CAS overlap guard | A tick arriving during a live cycle must be rejected atomically; a wrong decision here either double-polls or wedges the source. |
| `runCycle` → `pollruns.Store` (in-process seam) | Anything written becomes readable through the gated `/status` endpoint; the entry recorded on the failure paths is the disclosure surface. |
| `watchlist.Store.List` error → the recorded run entry | The underlying driver error is wrapped into the returned error; none of it may reach a `RunResult` field. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-18.1-07 | Information disclosure | the `store.List` error path's run entry | high | mitigate | `cycleErr` carries the wrapped driver error out as `runCycle`'s return value only; the `RunResult` gets `outcome=error` and zero counters and nothing else. `TestRunRecorder_RecordsErrorOutcomeOnListFailure` asserts the sentinel error's text is absent from the summary. |
| T-18.1-08 | Denial of service | run history eviction by skip-storm | medium | mitigate | An overlap-skipped tick never appends to the ring — `RecordSkip` only bumps a counter and a timestamp. Without this, a burst of skips during one slow cycle would evict all 50 real entries. Asserted by `TestRunRecorder_SkipRecordsNoEntry` (history length unchanged across a skipped tick). |
| T-18.1-09 | Denial of service | the overlap guard (`atomic.Bool` + `defer running.Store(false)`) | high | mitigate | The recorder defer is registered after the guard-release defer, so LIFO runs the recorder first and the guard release last, unconditionally. `TestRunRecorder_ErrorSwallowed` asserts `mbRunning` is `false` after an erroring and after a slow recorder. |
| T-18.1-10 | Denial of service | recorder retry loop | medium | mitigate | The failure is logged once and dropped — no retry, no backoff, no queue. Asserted by the exactly-one run-counter check in `TestRunRecorder_ErrorSwallowed`. |
| T-18.1-SC | Tampering | npm/pip/cargo installs | low | accept | No package-manager install in this plan; every symbol is in-repo or Go stdlib. RESEARCH.md "Package Legitimacy Audit": not applicable. |
</threat_model>
