Prove the entire Phase 6 architecture end-to-end with one production-quality vertical slice: a real user opens the single Go binary's URL in a browser and sees their real detected release history, rendered by an embedded React SPA that fetched it from a new `GET /events` endpoint backed by a new keyset-paginated sqlc query.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → Go API | Untrusted query strings and request paths cross into `internal/httpserver` |
| embedded FS → browser | Request paths select files out of the embedded SPA build |
| npm registry → build host | Third-party package code is fetched and executed at build time |
| Postgres → Go → browser | Externally-sourced text (MusicBrainz/Deezer titles) stored in Phase 4 flows out to the DOM |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-01 | Information Disclosure | `handleListEvents` error path | medium | mitigate | Never place raw DB/driver error text in the response; log it via `httplog.SetAttrs(..., slog.String("events_error", err.Error()))` and return the fixed operator-authored `"internal error"`, matching every existing handler (V13) |
| T-06-02 | Denial of Service | `GET /events` result-set size | high | mitigate | Page size is clamped inside `events.Service.List` (`DefaultPageSize` 24, `MaxPageSize` 100), not at the HTTP boundary, so no caller — HTTP or otherwise — can request an unbounded scan. This task's handler passes no client-supplied size at all |
| T-06-03 | Information Disclosure | `webassets.Handler` static file serving | medium | mitigate | Files are served exclusively from `fs.Sub` of an `embed.FS`; an embedded FS has no parent directory to traverse into and the OS filesystem is never consulted. `http.FileServer` additionally path-cleans before lookup |
| T-06-04 | Tampering | SQL injection through the events filters | high | mitigate | `ListEvents` is a single static sqlc-generated parameterized query; the `IS NULL OR` + `sqlc.narg` form exists specifically so no `WHERE` clause is ever assembled from strings in Go |
| T-06-05 | Spoofing | `r.NotFound` shadowing a real API route | medium | mitigate | chi matches every explicitly registered route before `NotFound`; `spa_test.go` asserts `/health` and `/events` still reach their own handlers rather than returning the SPA HTML |
| T-06-SC | Tampering | pnpm/npm package installs (16 packages) | high | mitigate | `06-RESEARCH.md`'s Package Legitimacy Audit plus Task 1's blocking human checkpoint gate every install; `make web` uses `--frozen-lockfile` and the lockfile is committed, so a later build cannot silently resolve a different version |
