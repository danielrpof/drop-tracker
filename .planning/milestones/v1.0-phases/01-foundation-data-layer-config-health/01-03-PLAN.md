## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| environment → process | All nine settings, including the DSN and the Discord webhook URL, cross into the process here. This is the only configuration ingress. |
| working tree → git history | `.env` (real values) versus `.env.example` (placeholders). Only the latter may cross. |
| config error → stderr | The fail-fast error naming missing variables crosses to the operator's terminal and to CI logs. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-08 | Information Disclosure | `.env` accidentally committed | high | mitigate | `.env` is git-ignored (verified at `.gitignore` line 151 and re-asserted by `TestDotEnvIsNotTracked` as an exact-line match plus an empty `git ls-files .env`). `.env.example` carries only local-development placeholders. The project-wide gitleaks pre-commit hook and CI backstop (CICD-02, CICD-10, Phase 7) are the second and third layers. Severity is high because the DSN embeds a password and this repository is a public portfolio project; the disposition is mitigate and the mitigation is verified in-phase by an automated test, so this does not block at the configured `security_block_on: high` threshold. |
| T-01-09 | Information Disclosure | fail-fast error message on stderr | medium | mitigate | The aggregate error names which variables are missing or unparseable; it must never echo a supplied value. `Load` returns `env.Parse`'s error unchanged, and `env.Parse` reports variable names and type-conversion failures rather than secret contents. `TestLoad_AggregatesAllMissing` asserts on names only, and the DSN redaction guarantee is covered end-to-end by plan 01-02's `TestNoDSNInLogs`. |
| T-01-10 | Tampering | configuration ingress | medium | mitigate | The process reads configuration from the environment only. A file-based or dotenv-based source would let a writable file in the working directory silently override an operator-supplied value. Enforced by two source assertions: no dotenv dependency in `go list -deps ./internal/config`, and no file-read call in `internal/config/config.go`. |
| T-01-11 | Denial of Service | malformed typed settings | low | mitigate | `caarlos0/env` type-converts `int`, `float64` and `time.Duration` fields and fails the parse on malformed input (ASVS V5, partial). A bad `POLL_INTERVAL` or `HTTP_PORT` terminates the boot rather than silently degrading to a zero value that would produce a busy-loop poller in Phase 3. |
</threat_model>
