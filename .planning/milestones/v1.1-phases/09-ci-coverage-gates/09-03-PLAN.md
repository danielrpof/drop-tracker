        no database and must not call `RequirePostgresDSN`.

        `POLL_INTERVAL` to a value long enough that no poll cycle can fire during the test, and
        `DISCORD_WEBHOOK_URL` to the empty string so the notifier resolves to its no-op selection.
        Create a cancellable context, run `run` in a goroutine writing its return value to a buffered
        channel of size one, then poll the reserved address's health endpoint on a short interval
        until it answers 200 or a generous deadline elapses — fail the test with a clear message if
        the deadline elapses first. Then cancel the context and assert, via a select against a
        timeout comfortably larger than the shutdown timeout constant, that `run` returned and that
        its returned error is nil. A shutdown that returns an error, or one that never returns, must
        fail the test rather than being tolerated.
