<objective>
Turn both measured, locally-green coverage gates into pipeline gates: run the backend gate inside the
`test` job, and complete `build-scan`'s dependency graph so a failure on either side stops the build
before anything is packaged or published.

Purpose: this is the plan that makes the phase goal true. Everything before it produced numbers and
mechanisms; this wires them into the `needs` graph that actually decides whether an image gets built,
scanned, and pushed to the registry. It runs last deliberately — wiring an 80% gate into CI before the
gap-closing plans landed would have turned main red mid-phase, and this repo commits straight to main
with no phase branch.

Output: one modified workflow file — one added step in the `test` job and one added entry in
`build-scan`'s `needs` array.
</objective>
