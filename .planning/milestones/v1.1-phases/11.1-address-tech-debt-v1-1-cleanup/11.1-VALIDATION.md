## Sampling Rate

- **After every task commit:** the relevant quick-run command scoped to the changed file (e.g. `go test ./cmd/server/... -run TestRun_BootServesHealthThenGracefulShutdownOnCancel -race -count=1`, or `pnpm --dir web test -- watchlist.test.tsx`)
- **After every plan wave:** full backend suite (`make test-integration`) for the backend wave; full frontend suite (`pnpm --dir web test`) for the frontend wave
- **Before `/gsd-verify-work`:** both full suites green, plus `make coverage-gate` (backend) and Vitest's inline threshold check (frontend) still passing at their existing 80%/70% floors — this phase adds test coverage, it must never *reduce* the measured percentage
- **Max feedback latency:** 1 task commit (per-task quick command; no watch-mode)
