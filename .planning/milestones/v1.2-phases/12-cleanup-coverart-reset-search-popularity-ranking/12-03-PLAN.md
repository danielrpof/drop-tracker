<objective>
Thread MusicBrainz's country code from its search response all the way to the search-result
row as a fallback hint when disambiguation is blank (D-08, D-09, D-10), and add the two
guardrails that keep the ranking work honest: MusicBrainz order is preserved end to end
(D-06, D-07) and Deezer's fan count never reaches the wire (D-05).

Purpose: the Watchlist search UI already renders MusicBrainz's disambiguation when it has
one — the actual gap is that MusicBrainz frequently leaves it blank, which is precisely the
"multiple Drakes" case a user needs help with. The country code is already in the response
body at zero extra API-call cost and nothing in this codebase decodes it.

Output: one new field in each of three layers (Go client struct, Go wire struct, TS mirror
type), a one-line render change in the existing label slot, and the tests that prove the
whole path plus the two negative guarantees.
