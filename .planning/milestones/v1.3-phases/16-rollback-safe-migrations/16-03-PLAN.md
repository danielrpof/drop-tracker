<objective>
Close the two gaps that make the static guard deterministic rather than advisory: compute the
diff base correctly for every event shape so the guard can never scan an empty set by
accident, and cross-reference every dropped or renamed object against the queries the
previously-released binary actually runs — so an `allow-destructive` annotation documents a
contract migration but can never wave through a live N-1 break.

This is the largest single addition to `cmd/migration-check` and the deterministic,
every-run counterpart to the `n1-boot` job's behavioural check.

Purpose: MGRT-01, decisions D-07 (revised), D-13, D-15, D-16, and RESEARCH Open Question 1.
Output: `--mode=changed-files`, the `gitShow` seam, the previous-release identifier extractor,
and the annotation-proof cross-reference.
</objective>
