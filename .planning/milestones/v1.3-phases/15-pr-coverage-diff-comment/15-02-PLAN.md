<objective>
Wire the plan-15-01 tool into the build: exclude `cmd/coverage-report` from the backend
coverage denominator (D-07), add a `make coverage-report` target that prints the backend total
(D-17), and refactor `make coverage-gate` to consume that number instead of measuring
independently — with a mandatory pre-cutover margin measurement so the switch cannot redden
`main`.

Purpose: this is the structural half of "the comment and the gate can never disagree". After
this plan there is exactly one implementation of "the backend coverage number" in the repo.

Output: a modified `Makefile` with an extended `COVER_PKGS` exclusion, a new phony
`coverage-report` target, and a `coverage-gate` recipe that shells the tool.
</objective>
