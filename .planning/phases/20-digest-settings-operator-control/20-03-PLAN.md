Save machinery, in its final shape:

- Local state is a single optimistic overlay, `pending: NotificationSettings | null`, plus a
  `status` value that is one of idle, saved, or failed. The rendered value is the overlay when
  present and the `settings` prop otherwise. This is what makes the keep-stale failure posture
  free: clearing the overlay puts the last-known-good value back on screen with no separate
  rollback bookkeeping, and a `Refresh` in the parent replaces the prop without any resync
  effect.
- A `savingRef` boolean ref is the re-entrancy guard, checked and set synchronously before the
  first await — not the rendered disabled flag. A state-only guard demonstrably lets two
  interactions dispatched in the same task both start a request; 19-05 proved that with a real
  double-click.
- A `mountedRef` guards every post-await state write, mirroring `system.tsx`'s own handler.
- On a change: set the overlay to the next value, disable the control, call
  `updateDigestSettings`. On success, call `onSaved` with the server's response, clear the
  overlay, set status to saved, and schedule a 2-second clear of that confirmation with a
  timer whose handle is kept in a ref, cleared on unmount and cancelled/replaced by any later
  save. On failure, clear the overlay, set status to failed, and swallow a 401 the way
  `system.tsx` does — `err instanceof ApiError && err.status === 401` returns before any state
  write, because the passphrase screen is already taking over.
- Below the `dl`, render one shared status region: a `<p role="status" aria-live="polite">`
  copying the markup of `system.tsx`'s existing refresh-error line, carrying the locked copy

  failed. One region serves every control on this card. The confirmation is deliberately muted
  rather than green: the run-health palette tokens reserved by `19-UI-SPEC.md` are a closed
  list and this is a completed user action, not a health signal — so neither of those two
  tokens may appear in this file. The card contains no button element of any kind (D-02).
