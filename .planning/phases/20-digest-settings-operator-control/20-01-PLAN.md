<objective>
Ship the digest settings spine end to end in one production-quality slice: a singleton
`notification_settings` row in Postgres, a narrow `internal/settings.Store` over generated
sqlc queries, and gated `GET`/`PUT /settings/notifications` routes wired at the composition
root — proven by a real HTTP round-trip against a real migrated database.

slice. If the migration shape, the singleton enforcement, the seam, or the route placement is
wrong, that is a one-commit correction here instead of a three-plan unwind. It also freezes
the wire contract plan 20-03 types `web/app/lib/api.ts` against.

Output: an operator-changeable, restart-surviving digest setting reachable over HTTP, with
real-time notification behavior untouched.
</objective>

000005's convention. Create the paired `000008_notification_settings.down.sql` as a single
