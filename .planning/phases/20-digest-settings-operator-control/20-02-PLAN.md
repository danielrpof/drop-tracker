## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| unauthenticated browser → gated API | a caller with no session cookie reaching either settings verb |
| cross-site page → gated API | a forged `PUT` issued from another origin against an authenticated browser |
| store failure text → HTTP response | a database error whose message can embed a DSN or webhook URL |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-20-07 | Spoofing | settings routes on a gated instance | high | mitigate | Task 2 proves with a live request that both verbs answer 401 without a session, and that the 401 body leaks no settings key. The control itself is `gate.Authenticate` inherited from `registerDataRoutes` (plan 20-01); this plan converts that structural claim into a behavioral test. |
