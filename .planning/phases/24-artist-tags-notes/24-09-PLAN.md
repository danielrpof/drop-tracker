<objective>
Close verification gap 2, the plan 24-06 key link that was only half wired (code review WR-01). `dropTagFromEntries` in
`web/app/routes/watchlist.tsx` removes the deleted tag from every card but leaves it in the route `vocabulary`.
`vocabularyStatus` stays `loaded`, so nothing refetches. Every row's "+ tag" autocomplete therefore keeps offering the
deleted tag as an existing suggestion, and picking it silently re-creates the tag. The fix adds the same functional
vocabulary update that rename and merge already make, plus a route test that fails on current code.

`internal/webassets/build/client`, which every `go test ./...` compiles through go:embed) and runs the whole-phase
Definition of Done against the shared dev Postgres. Running either step at the same time as 24-08's backend suite would
race on the same working tree and the same `migrate_scratch` schema. The frontend fix itself does not depend on 24-08.

Purpose: SC4's delete disappears from the whole UI, including the autocomplete (TAG-06, D-17, D-30).

</objective>
