<objective>
Close the three open UAT gaps from the phase 24 UI audit (24-UI-REVIEW.md top 3 fixes, logged as G-24-9..11). Each root cause is diagnosed and confirmed in code:

- **G-24-9 (blocker).** ArtistNote's overflow `useLayoutEffect` (lines 89-102) measures `scrollHeight > clientHeight` from a ResizeObserver. Expanding removes `line-clamp-2`, so the paragraph grows and the observer re-measures. `overflow` turns false, and the `{overflow && <button>}` toggle (line 252) unmounts. The user cannot collapse the note, and focus drops to body.
- **G-24-10 (minor).** ManageTagsDialog mounts while `status` is `loading`. base-ui's initial focus lands on the close x, the only tabbable element at that point. Nothing moves focus when the list loads (lines 95-125), which breaks UI-SPEC focus row (d): "Dialog opens -> row 1's Rename".
- **G-24-11 (minor).** ArtistNote.tsx:179 passes an unprefixed `text-label` to the note Textarea. It overrides the built-in 16px `text-base` below md, and that triggers iOS Safari's zoom on focus.

The fixes follow each gap's `missing` list:

1. Latch the overflow measurement while expanded, so it only ever measures the clamped paragraph.
2. Hand focus to row 1's Rename on the first load of each open, but only from the popup, its close button, the body, or outside the popup.
3. Drop the unprefixed `text-label`.

Each fix gets a component test. Task 3 rebuilds the embedded SPA and runs the phase-closing Definition of Done.

G-24-4 and G-24-5 are already resolved and are out of scope.

Wave 1, with no dependencies: 24-01..24-13 are complete. Nothing here touches the backend, routes, the API module, or the vendored ui layer.

Purpose: a keyboard or screen-reader user can expand and collapse a long note without losing focus. Manage tags opens straight onto the first actionable row. Editing a note on a phone no longer zooms the page.
Output: two component fixes (one effect plus one className in ArtistNote, one ref plus one layout effect in ManageTagsDialog), four new component tests, the refreshed embedded bundle, and a green whole-phase gate.
</objective>
