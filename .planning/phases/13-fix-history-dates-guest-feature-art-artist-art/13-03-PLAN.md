## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| HTTP client → POST /watchlist | Untrusted request whose handling now triggers outbound third-party calls before responding |
| drop-tracker → api.deezer.com / musicbrainz.org | Outbound calls made both per-add and per-swept-artist, on the process-wide shared rate limiters |
