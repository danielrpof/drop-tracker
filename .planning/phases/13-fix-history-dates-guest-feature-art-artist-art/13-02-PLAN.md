<objective>
Build the single artist-art matching function both of bug #3's call sites will share, plus the read query the backfill sweep needs.

Purpose: every `artists.image_url` in this database is NULL and always has been — MusicBrainz has no artist images, and adds only ever flow from a MusicBrainz search result. Deezer has artist pictures but no MusicBrainz id, and this project has deliberately never had cross-source identity resolution. D-08 defines the narrow, fail-closed resolution rule that makes Deezer's pictures usable without ever attaching a wrong artist's photo.

Output: a new `internal/artistart` package containing the match rule and its narrow upstream seams, fully unit-tested against stubs with no real HTTP, and a new sqlc query listing the artists a backfill must sweep.
</objective>

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-13-08 | Information Disclosure | Error paths inside `Match` | low | mitigate | This package builds no HTTP requests of its own — every outbound call goes through the existing `deezer`/`musicbrainz` client methods, which already return status-code-only errors and never echo a response body. `Match` wraps those errors without adding upstream text. |
