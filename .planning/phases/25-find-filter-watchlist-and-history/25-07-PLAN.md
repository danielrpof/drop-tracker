|-----------|----------|-----------|----------|-------------|-----------------|
| T-25-20 | Denial of Service | Oversized `tags=` list | low | mitigate | Parse at most 200 tokens, accept only `^[1-9]\d*$`, then intersect with the payload's tag ids on first load and rewrite with replace |
| T-25-21 | Tampering (XSS) | Tag names in chips, options, `title`, `aria-label` | medium | mitigate | Plain JSX text and React-escaped attributes only; no HTML injection API anywhere in the new component (Phase 06 posture) |
| T-25-22 | Tampering | Tag filter ↔ server state | low | mitigate | The filter never calls attach/detach/delete; Manage tags remains the only path that mutates tags, and it only *reports* to the filter |
