<objective>
Fix the CoverArt image-load-error state so it resets when `src` changes on a retained
component instance (D-01), and lock the fix in with a regression test (D-02).

forever, even when a later `src` would succeed. `CoverArt` is shared by History rows,
Watchlist rows and search-result rows, so the stale placeholder shows up across three
surfaces from one bug.

covering the reset plus the two behaviors the reset must not break.
