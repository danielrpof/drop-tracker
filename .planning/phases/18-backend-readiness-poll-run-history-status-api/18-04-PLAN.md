## The frozen `/status` contract

**This is the freeze point.** Phase 19 types `web/app/lib/api.ts` against this exact body.
`docs/api/status-contract.md` (task 3) is the durable home for it; this table is the
source that file is written from.

`GET /status` — gated. 401 with no valid session. 200 otherwise.

| JSON path | Type | Notes |
|---|---|---|
| `poll_interval_seconds` | int | Configured poll interval truncated to whole seconds. 900 for the 15-minute default. |
| `watchlist_size` | int | From `CountWatchlist`. |
| `instance.app_version` | string | Short SHA, at most 12 characters, on a CI-built image; `dev` on a flagless local build. |
| `instance.schema_applied` | int or null | Live read. `null` only when the database is unreachable at request time. |
| `instance.schema_expected` | int | The boot-time value. Same key names as `/ready`'s body — one schema-version concept, not two. |
| `sources` | object | Keyed by source name. Always carries exactly `musicbrainz` and `deezer`, including on a fresh instance. |
| `sources.<name>.last_run` | run object or null | `null` until that source records its first cycle. Equals `history[0]` when present. |
| `sources.<name>.history` | array of run objects | Newest-first. Empty array — never `null` — when nothing has been recorded. At most 50 entries. |
| `sources.<name>.last_skipped_at` | RFC3339 string or null | `null` until that source is first overlap-skipped. |
| `sources.<name>.consecutive_skips` | int | Reset to 0 by the next recorded run. |

Run object (used by both `last_run` and every `history` element):

| JSON key | Type | Notes |
|---|---|---|
| `cycle_id` | string | The existing per-cycle correlation id. |
| `started_at` | RFC3339 string | |
| `finished_at` | RFC3339 string | |
| `duration_ms` | int | |
| `artists_checked` | int | Entries dispatched to a worker. |
| `artists_skipped` | int | Entries skipped before dispatch. |
| `artists_errored` | int | |
| `events_recorded` | int | Zero until Phase 18.1 populates it. |
| `outcome` | string | Closed set: `ok`, `error`, `cancelled`. |
| `summary` | string | Composed from the counts and the outcome by the store; never derived from an error. |

The run object deliberately has **no** `source` key — the source is the map key — and the
envelope has **no** `error`, `detail`, `message` or `last_error` key anywhere, at any depth.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| authenticated client → `/status` | A session-bearing operator — including one who got in past a weak passphrase, which the boot path only warns about — reads an aggregate of internal state. |
| handler → Postgres | Two reads on the shared pool; a connection failure produces an error whose text embeds the DSN with its password. |
| run store → response encoder | Values recorded by the poll cycle, where driver errors and webhook URLs are in scope, are serialized to that client. |
| `queries/` → generated package | The only drift gate is local; a forgotten regeneration ships green through CI. |
