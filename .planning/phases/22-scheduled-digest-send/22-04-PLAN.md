## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| container image → host zoneinfo | the runtime's tzdata (absent on Alpine) determines every computed fire instant |
| CI runner → throwaway Postgres | a short-lived unauthenticated database on the runner's host network |
| CI runner → the built image | the artifact under test is the same one `release` later pushes |

A test that merely asserted the process started would not distinguish the two. |

| T-22-20 | Information Disclosure | CI throwaway Postgres | low | accept | The credentials are the literal `drop_tracker`/`drop_tracker` pair `n1-boot` already uses for its own throwaway instance, in a container destroyed at job end on an ephemeral runner.
