<mechanism_note>
The graphify ignore file uses gitignore-style pattern syntax and is read from the corpus root. Its patterns are authoritative even for git-TRACKED files — unlike a plain gitignore, whose patterns graphify's `detect.py` deliberately does not apply to paths already present in git's index. That is precisely why this is the right mechanism: it removes planning noise from the graph without untracking a single file from git. Verified by direct inspection of `C:/Users/danie/.local/graphify-venv/Lib/site-packages/graphify/detect.py`.
</mechanism_note>
